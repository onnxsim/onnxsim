Knowledge distillation, live in your browser

A tiny student model learns from a frozen teacher via ONNX Runtime Web's on-device training API -- no server-side compute.

Scope: this trains a microscopic ~22K-parameter toy architecture (real attention/RoPE/RMSNorm, same shape as examples/llm_distillation/distill.py's TINY_SPEC), not the ~1B/~162M-parameter models that Python demo trains -- PyTorch has no WASM build, and that scale doesn't fit WASM's memory ceiling regardless. This demonstrates the distillation mechanics (real gradients, real KD loss, real optimizer steps) working end to end client-side, on synthetic random token ids, not a useful language model.
